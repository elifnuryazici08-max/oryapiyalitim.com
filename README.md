# ORYAPI Yalıtım – Web Sitesi

ORYAPI İnşaat Nakliye ve Yapı Malzemeleri için yeniden tasarlanan kurumsal site.

- `index.html` – Ana sayfa (kurumsal, faaliyetler, bayilikler şeridi, iletişim)
- `bayiliklerimiz.html` – Bayilik markaları
- Bayi logosu eklemek için: dosyayı `images/bayiler/` klasörüne koyun ve `js/main.js` içindeki `BRANDS` listesinde ilgili markaya `logo: "dosya.png"` yazın.
